# Deploy MailBrief on Render

Step-by-step guide to publish your SaaS on [Render](https://render.com).

## What you need

- GitHub account
- [Render](https://render.com) account (free tier works)
- Groq API key
- Google OAuth credentials (`gmailautomation.json` content)

---

## Step 1 — Push code to GitHub

```bash
cd /home/sha/Gmail
git init
git add .
git commit -m "MailBrief SaaS"
git remote add origin https://github.com/YOUR_USERNAME/mailbrief.git
git push -u origin main
```

**Do not commit:**
- `.env`
- `gmailautomation.json`
- `token.json`
- `mailbrief.db`

These are already in `.gitignore`.

---

## Step 2 — Create Render services

### Option A — Blueprint (recommended)

1. Go to [dashboard.render.com](https://dashboard.render.com)
2. Click **New → Blueprint**
3. Connect your GitHub repo
4. Render reads `render.yaml` and creates:
   - **Web service:** `mailbrief`
   - **PostgreSQL:** `mailbrief-db`

### Option B — Manual

1. **New → PostgreSQL** → name `mailbrief-db` → Free
2. **New → Web Service** → connect repo
   - **Runtime:** Python 3
   - **Build command:** `pip install -r requirements.txt`
   - **Start command:** `bash scripts/render_start.sh`
   - **Health check path:** `/`

---

## Step 3 — Set environment variables

In Render → your web service → **Environment**:

| Key | Value |
|---|---|
| `GROQ_API_KEY` | your Groq key |
| `GOOGLE_CREDENTIALS_JSON` | paste full contents of `gmailautomation.json` as one line |
| `APP_URL` | `https://mailbrief.onrender.com` (your Render URL) |
| `GMAIL_REDIRECT_URI` | `https://mailbrief.onrender.com/auth/gmail/callback` |
| `DATABASE_URL` | auto-linked if using Blueprint, or copy from PostgreSQL dashboard |
| `SECRET_KEY` | auto-generated by Blueprint, or run `openssl rand -hex 32` |

Render sets `RENDER_EXTERNAL_URL` automatically — the app uses it if `APP_URL` is not set.

### How to set `GOOGLE_CREDENTIALS_JSON`

On your machine:

```bash
cat gmailautomation.json | jq -c .
```

Copy the single-line JSON and paste it as the env var value in Render.

---

## Step 4 — Update Google OAuth

In [Google Cloud Console](https://console.cloud.google.com/):

1. **OAuth consent screen** → External → Publish (or add test users)
2. **Credentials → OAuth client** → add:

**Authorized redirect URIs:**
```
https://YOUR-APP.onrender.com/auth/gmail/callback
```

**Authorized JavaScript origins:**
```
https://YOUR-APP.onrender.com
```

Replace `YOUR-APP` with your actual Render subdomain.

---

## Step 5 — Deploy

1. Click **Manual Deploy → Deploy latest commit** (or push to GitHub for auto-deploy)
2. Wait for build to finish (2–5 min)
3. Open your Render URL: `https://mailbrief.onrender.com`

---

## Step 6 — Test

1. Register at `/register`
2. Connect Gmail
3. Add your Telegram bot token + chat ID
4. Enable automation
5. Send yourself a test email

## Render free tier notes

| Limit | Impact |
|---|---|
| Web service sleeps after 15 min idle | First visit may take ~30s to wake up |
| Free PostgreSQL expires after 90 days | Upgrade or export data before expiry |
| 512 MB RAM | Fine for early users |

For production with paying users, upgrade to **Starter** ($7/mo web + $7/mo DB).

---

## Custom domain (optional)

1. Render → web service → **Settings → Custom Domains**
2. Add `mailbrief.yourdomain.com`
3. Update DNS CNAME to Render
4. Update `APP_URL`, `GMAIL_REDIRECT_URI`, and Google OAuth URLs to your custom domain

---

## Troubleshooting

| Problem | Fix |
|---|---|
| Build fails | Check Render logs → ensure `requirements.txt` installs |
| `GROQ_API_KEY is required` | Add env var in Render dashboard |
| Gmail OAuth redirect mismatch | Update Google Cloud redirect URI to match Render URL exactly |
| `Google OAuth credentials missing` | Set `GOOGLE_CREDENTIALS_JSON` env var |
| Database connection error | Confirm `DATABASE_URL` is linked to PostgreSQL service |
| App sleeps / slow first load | Normal on free tier — upgrade to Starter |
